# SleepSync - Научно-обоснованный калькулятор циклов сна

**SleepSync** — это современное, переработанное веб-приложение, которое помогает рассчитать оптимальное время для сна и пробуждения. Оно основано на научных данных о естественных циклах сна и предлагает как простой и быстрый калькулятор, так и продвинутый персонализированный режим.

**[➡️ Live Demo](https://sleepsync.ipirojnoe.ru)**

---

## ✨ Ключевые особенности

* **Два режима расчета:**
    * **Простой режим:** Быстрый расчет на основе научно установленной медианной продолжительности цикла в 96 минут.
    * **Продвинутый режим:** Персонализированный расчет длительности цикла на основе ваших данных (возраст, пол, хронотип) и факторов образа жизни, подкрепленный научными исследованиями.
* **Научная обоснованность:** Приложение включает отдельную страницу с подробным **[обзором научных исследований](science.html)** о циклах сна и их влиянии на самочувствие.
* **Современный UX/UI:**
    * Полностью адаптивный дизайн, построенный на **Bootstrap 5**.
    * Поддержка светлой и тёмной тем.
    * Чистый, интуитивно понятный и доступный интерфейс.
* **Полезный экспорт:**
    * **Добавить в календарь:** Скачайте файл `.ics`, чтобы добавить рекомендованное время сна или пробуждения прямо в ваш календарь.
    * **Экспорт в текст:** Получите краткий отчет с результатами
* **PWA (Progressive Web App):** Приложение можно установить на телефон и использовать офлайн.

## 🔬 Научная основа

Проект не просто использует устаревшее "правило 90 минут". Расчеты основаны на актуальных исследованиях:

* **Cajochen et al. (2024):** Крупнейший на сегодняшний день анализ, установивший медианную продолжительность цикла в **96 минут** и выявивший её зависимость от возраста и пола.
* **Roenneberg et al. (2007):** Основополагающее исследование о влиянии хронотипов ("совы" и "жаворонки") на циркадные ритмы.
* **Phillips et al. (2017):** Работа, доказывающая, что регулярность сна важнее строгого следования циклам.

## 🚀 Как запустить локально
1.  Клонируйте репозиторий:
    ```bash
    git clone [https://github.com/ipirojnoe/sleepsync.git](https://github.com/ipirojnoe/sleepsync.git)
    ```
2.  Перейдите в папку проекта:
    ```bash
    cd sleepsync
    ```
3.  Откройте `index.html` в браузере. Для корректной работы PWA (Service Worker) **рекомендуется** использовать локальный веб-сервер, например, [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) для VS Code.
